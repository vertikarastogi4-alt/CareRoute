# CareRoute 🏥

### AI-Powered Healthcare Access & Alternative Care Pathway Engine

> **From knowing WHAT care is needed to finding WHERE and HOW it can realistically be accessed.**

## 🚨 Problem

Patients often receive a healthcare recommendation but struggle to find an option that fits their **budget, location, travel distance, availability and accessibility needs**.

## 💡 Solution

CareRoute converts a doctor's recommendation into a **personalized and feasible care pathway**.


Doctor Referral
      ↓
Patient Constraints
      ↓
CareRoute Matching Engine
      ↓
Ranked Facilities
      ↓
Best Option + Alternatives

⭐ Key Features
👨‍⚕️ Digital doctor referrals
👤 Patient constraint collection
🧠 AI/NLP-based requirement extraction
📍 Location & distance matching
💰 Budget-aware facility matching
🏥 Facility discovery and verification
🔄 Alternative care pathways
📊 Healthcare-access analytics
🔐 Consent & privacy-focused design
🛠️ Tech Stack

Frontend: React.js, Vite, Tailwind CSS, PWA
Backend: Node.js, Express.js
Database: PostgreSQL
AI: Python, FastAPI, NLP/LLM
Other: Maps/Geolocation, ABDM/HFR integration where applicable

🧮 Matching Engine

Facilities are filtered and ranked using:

Factor	Weight
Service Fit	30%
Distance	25%
Cost	20%
Availability	15%
Eligibility	10%

The system provides an explainable Feasibility Score.
